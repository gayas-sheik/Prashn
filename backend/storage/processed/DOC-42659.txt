1. Introduction
The proposed project is a Cloud-Native Event-Driven Document Processing Platform.
The main purpose of the system is to allow users to upload documents such as invoices,
receipts, application forms, IDs, or other semi-structured files and automatically process them in
the cloud.
Instead of making the user manually read the document and enter information, the platform can
automatically:
The main objective of the project is not simply document extraction. The document-processing
use case is used to demonstrate important cloud-computing concepts such as event-driven
architecture, asynchronous processing, serverless computing, message queues, scalability,
fault handling, monitoring, security, Infrastructure as Code, CI/CD, and cost optimization.
